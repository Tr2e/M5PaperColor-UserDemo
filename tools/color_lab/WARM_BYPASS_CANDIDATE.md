# 暖色旧补偿旁路候选（2026-09-10）

接续IMG_9942：保留当前温和减白作为实验设置、保留彩色比和已通过的边缘保护，回完整24色表单独检查14号橙色。新增默认关闭 `PAPERCOLOR_WARM_COMPENSATION_BYPASS`，跳过旧暖色分支；不引入新的经验补偿系数。

## 已确定的原因与尚未确定的效果

旧分支在红黄候选集合内，满足 `B>=32 && R-G>=80` 时将源R乘7/8、B乘3/4，G不变。这两个条件是硬开关。14号原图 `(255,102,51)` 经RGB565变成 `(255,101,49)`，被改成 `(223,101,36)` 后才进入原色域投影。

旁路后仍使用相同的标称颜料、投影、LUT及FS/Burkes，不再先压低这两个通道。14号标称Q4投影目标从 `(217.75,102.375,35.9375)` 变为 `(219.6875,110.4375,48.4375)`。这是内部RGB目标，不是实物屏幕测量。

软件根因是阈值补偿引入的目标突变和源值压低；不能据此断言橙色还原不佳全部由它造成。旁路会增加橙色白份额，可能改善偏沉，也可能变灰或增加高反差颗粒。必须实拍再决定是否保留。

蓝紫/青蓝两段旧补偿仍保留，不能宣称全部旧补偿已移除。13、15的源B为0，原先并不触发此暖色分支，它们的目标保持不变。

## 测试的验收口径

原host测试有“橙色白份额<10%”的基线要求，新实验按设计不满足它。此要求在新开关关闭时原样保留；只对旁路实验增加独立投影预期的覆盖检查，不把增加白色自动视为视觉改善。实际完整色表白约11.31%，均匀场因边界上下文不同约11.61%；RGB888直接输入与RGB565也不能混为完全相同输入。

默认host、候选ASan/UBSan、两种滤波器的橙色覆盖比例、新旧阈值连续性回归、已有纯色/连线边缘/灰阶/长残差/RGB888与565等价检查通过。H5源图预览及10项Python回归通过。没有修改UI、网络、存储或驱动波形。
