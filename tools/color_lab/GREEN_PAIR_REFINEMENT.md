# IMG_9959 绿系正式候选

基于IMG_9958保留基线，将IMG_9959的B/B/B方向推广到照片映射：

- 绿主导黄绿最多把彩色覆盖的1/16从黄转到绿；
- 绿主导青绿最多把彩色覆盖的1/16从绿转到蓝；
- 同一暗/中青绿最多把40%的白转为校正后的绿蓝混合，保持黑量和绿蓝比例。

各项在源色色相、彩度、亮度及目标颜料可用量上连续淡入；黄/绿边界、纯颜料、近青色
已通过的校正窗口和浅色青绿受到保护。最初直接推广“减半白色”会在浅色青绿的RGB565
相邻单元形成新大步阶，因此未采用；40%版本没有新增旧步阶不超过30而新步阶超过30的边。
